# AI Usage Report

## AI Tools Used

I used ChatGPT and Claude during the development of this assignment.

## ChatGPT

I used ChatGPT to understand how to correctly structure the project, organize the files, and connect the project to GitHub. Since I am a beginner when it comes to GitHub, this project was useful for helping me understand how to start a personal project, organize its files, and connect it to a GitHub repository.

## Claude

I then used Claude to generate the HTML, CSS, and JavaScript files for the website. I provided Claude with the information and requirements that I wanted to be displayed on my portfolio, including my projects, interests, contact form, and the features required for the assignment. Claude generated the initial versions of the website files based on these requirements.

## How I Used AI Output

After Claude generated the website, I tested the files to make sure the website worked correctly and that the different features functioned as expected.

I reviewed the generated code and made several changes myself. For example, Claude initially included a profile image section with a placeholder image. I decided that I did not want a profile image, so I removed the profile image section from the HTML and the related CSS.

Claude also included placeholder content in some areas of the website. I removed unnecessary placeholder text and adjusted the content so that it better represented my actual projects and interests.

I also cleaned up unused CSS and added a hover effect to the project cards. The hover effect uses CSS `transform`, `box-shadow`, and `transition` properties to make the cards slightly lift when the user moves the cursor over them.

## Benefits and Challenges

I found this assignment helpful because it connected everything we have learned since the start of the semester. It was also good practice for learning how to make my own project and connect all the files to GitHub.

It was satisfying to see everything come together and learn new things about how all the elements are connected through a working website.

One challenge was that the AI-generated code sometimes included elements that I did not need, such as the profile image section and unused CSS. I had to review the generated code and decide which parts were relevant to my website instead of using everything exactly as it was generated.
